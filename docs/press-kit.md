**Stand: Juni 2026**

## Projektbeschreibung

OpenNoiseNet ist eine offene, datenschutzkonforme Plattform für Lärm-Monitoring, die Bürger:innen, Wissenschaft und Verwaltung belastbare Echtzeit-Daten zur Lärmbelastung bereitstellt. Statt teurer, stationärer Messstationen setzt OpenNoiseNet auf ein dezentrales Netzwerk aus kostengünstigen, smartphone-gekoppelten Messgeräten — betrieben von Anwohner:innen, Initiativen und Kommunen.

Die Plattform umfasst eine öffentliche Lärmkarte mit anonymisierten Messwerten, ein persönliches Dashboard für Teilnehmer:innen sowie ein Pro-Modul für Betreiber mit Episode-Erkennung, Fall-Management und rechtssicheren Export-Funktionen. Alle Komponenten sind Open Source (MIT-Lizenz), die Daten stehen unter ODC-ODbL. Der Betrieb erfolgt auf deutschen Servern mit Ende-zu-Ende-Datenschutz nach DSGVO.

Im Juli 2026 startet das Hamburger Pilotprogramm mit 100 Messgeräten, unterstützt von Partnern aus Wissenschaft und Zivilgesellschaft.

## Technologie-Stack

| Komponente | Technologie |
|---|---|
| Backend API | Python (FastAPI), PostgreSQL, Redis |
| Public Map | Next.js (React), Leaflet/MapLibre |
| Pro Dashboard | React (Vite), TypeScript |
| Mobile App | Flutter (iOS, Android) |
| Messgerät-Firmware | ESP32, MEMS-Mikrofon |
| Infrastruktur | Docker, Nginx, Cloudflare Tunnel |
| Daten-Lizenz | ODC Open Database License (ODbL) |
| Code-Lizenz | MIT |

## Gründer-Statements

> „Lärm ist das unterschätzte Umweltproblem unserer Städte. Mit OpenNoiseNet geben wir Bürger:innen ein Werkzeug, um Lärmbelastung sichtbar zu machen — evidenzbasiert, datenschutzkonform und gemeinschaftlich."

> „Wir bauen bewusst auf Open Source und offene Daten. Lärmschutz darf kein teures Gutachten-Produkt sein — es braucht eine demokratische Datengrundlage, die allen zugänglich ist."

- **5+** Partner-Organisationen
- **Pilot-Budget:** Community-finanziert, Sachspenden
