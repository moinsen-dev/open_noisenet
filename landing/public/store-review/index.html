Android foreground microphone demonstration

OpenNoiseNet 0.1.0 (6), running locally on Android 15 with 16 KB pages. This demonstration on a clean test device has no audio track and uses no personal field-test data.

Download the demonstration (MP4)

  1. The user taps Start Sensor Mode.
  2. While the app is backgrounded the Android microphone indicator and OpenNoiseNet monitoring notification remain visible.
  3. The user returns to the app and presses Stop. The sensor returns to idle.
